Overview

HTML Garage is a web-based governance and certification platform for citizen-developer HTML tools. It provides a structured process — modelled on the MOT testing regime for motor vehicles — that lets Tech Services set and enforce security standards while giving citizen developers a clear, low-friction path to compliance.

Tools that pass the certification process receive a CMMYY code embedded in the HTML and an entry in the central registry. Tools without a CMMYY code are unlicensed and can be identified and acted upon by Tech Services.

Problem Statement

The landscape

AI coding assistants have made it practical for non-developers to build standalone HTML and JavaScript tools. These tools are created outside formal development processes, deployed from local machines or shared drives, and used to deliver real business value.

Where they help

  • Simulated dashboards — validate a proposed data product with business users before any build investment.
  • Analytical output presentation — compress time from insight to decision with interactive HTML tools.
  • Desktop planning tools — encode repeatable business processes without IT dependency.

The risks

RiskDescription
Supply chain attackTools loading JS from public CDNs are exposed to library compromise. Developers have no visibility.
Data ingestionMany tools ingest sensitive data files with no handling controls, audit trail, or access restrictions.
Code injectionUnvalidated inputs in tools that process external files are attack surfaces.
Shadow processBusiness processes running on unsupported tools will fail when the tool fails. No support path exists.
No enforcement boundaryWithout a central register, Tech Services cannot distinguish reviewed tools from unreviewed ones.

Solution

HTML Garage introduces a governance model built around periodic certification, a central registry, and an enforcement boundary.

A certified tool carries a _CMMYY suffix in its filename (e.g. dashboard_C1026.html), an embedded certification footer, and a registry entry. A tool without these markers is unlicensed. Tech Services can spot the difference visually and verify formally via the Audit function.

Architecture

The app runs entirely client-side. No server-side code. The Tile platform provides SQLite access, file storage, and user identity. All security logic runs in the browser.
